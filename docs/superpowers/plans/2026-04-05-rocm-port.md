# ROCm/HIP Port of Flash-MoE CUDA Backend — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the CUDA inference engine (`cuda_infer/`) to AMD ROCm/HIP, targeting MI300X (CDNA 3, gfx942, wavefront-64) as primary and consumer RDNA GPUs (gfx1100/gfx1201, wavefront-32) as secondary.

**Architecture:** Copy `cuda_infer/` to `rocm_infer/`, mechanically translate CUDA→HIP APIs, then adapt kernels for AMD wavefront sizes. The engine structure (model loading, forward pass, HTTP server, VRAM LRU cache, SSD streaming) stays identical. GDS (cuFile) is removed — AMD has no equivalent; only the pread + page cache path is kept.

**Tech Stack:** HIP (hipcc compiler), ROCm 7.x runtime, same C/pthreads I/O layer. No new dependencies.

---

## File Structure

```
rocm_infer/
  infer.hip            # Copy of infer.cu, CUDA→HIP API translation
  kernels.hip.h        # Copy of kernels.cuh, CUDA→HIP kernel translation
  Makefile             # hipcc-based build system
  tokenizer_impl.c     # Unchanged (symlink or copy from cuda_infer/)
  configure.py         # Unchanged (symlink or copy)
  build_expert_index.py # Unchanged (symlink or copy)
  export_vocab.py      # Unchanged (symlink or copy)
  README.md            # ROCm-specific docs
```

Key decision: **copy, not symlink** the main `.cu`/`.cuh` files. The CUDA and ROCm backends will diverge in non-trivial ways (wavefront handling, no GDS, different memory hints). Keeping them separate avoids `#ifdef` spaghetti. Python scripts and `tokenizer_impl.c` can be symlinked since they have no GPU-specific code.

### Task 2: Port `kernels.cuh` → `kernels.hip.h`

This is the most critical task. 15 kernels need CUDA→HIP translation. The changes fall into categories:

**A. Mechanical replacements (all kernels):**
- `#include <cuda_runtime.h>` → `#include <hip/hip_runtime.h>`
- `#include <cuda_fp16.h>` → `#include <hip/hip_fp16.h>`
- `__shfl_down_sync(0xFFFFFFFF, val, offset)` → `__shfl_down(val, offset)` (HIP has no mask — full wavefront always participates)
- `__ldg(ptr)` → `__ldg(ptr)` (HIP supports `__ldg` — no change needed)
- `__fmaf_rn(a, b, c)` → `fmaf(a, b, c)` (HIP uses standard math)
- `__half2float(x)` → `__half2float(x)` (HIP supports this)
- `uint4` vector loads → manual `struct { uint32_t x,y,z,w; }` (HIP `uint4` is not identical to CUDA's)

**B. Wavefront-size adaptation (warp reduction helpers, all kernels using them):**
- CUDA warp = 32 lanes, mask `0xFFFFFFFF`
- MI300X wavefront = 64 lanes, no mask needed
- RDNA wavefront = 32 lanes, no mask needed
- The reduction loop `for (offset = 16; offset > 0; offset >>= 1)` must use `WARP_SIZE/2` as starting offset
- Shared memory for cross-warp reduction uses `shared[32]` — must become `shared[WARP_SIZE]` or be computed from `blockDim.x / WARP_SIZE`

**C. Launch config changes (launch helpers):**
- `dim3 block(32, ROWS_PER_BLOCK)` — the `32` is warp size, must become `WARP_SIZE`
- Cooperative load loops use `32 * ROWS_PER_BLOCK` stride — must become `WARP_SIZE * ROWS_PER_BLOCK`
- Grid calculations unchanged

- [ ] **Step 7: Replace hardcoded `32` with `WARP_SIZE` in all kernels**

In every kernel, replace warp-size-dependent constants:

1. **Cooperative load strides**: `32 * ROWS_PER_BLOCK` → `WARP_SIZE * ROWS_PER_BLOCK`

6. **Warp ID calculation**: `threadIdx.x / 32` → `threadIdx.x / WARP_SIZE`
7. **Lane in warp**: `threadIdx.x % 32` → `threadIdx.x % WARP_SIZE`

## Summary: CUDA→HIP Translation Reference

| Category | CUDA | HIP | Notes |
|----------|------|-----|-------|
| Header | `cuda_runtime.h` | `hip/hip_runtime.h` | |
| Header | `cuda_fp16.h` | `hip/hip_fp16.h` | |
| Header | `cufile.h` | *(removed)* | No AMD GDS equivalent |
| Malloc | `cudaMalloc` | `hipMalloc` | |
| Pinned | `cudaMallocHost` | `hipHostMalloc` | |
| Memcpy | `cudaMemcpy` | `hipMemcpy` | |
| Memset | `cudaMemset` | `hipMemset` | |
| Free | `cudaFree` | `hipFree` | |
| Stream | `cudaStream_t` | `hipStream_t` | |
| Sync | `cudaDeviceSynchronize` | `hipDeviceSynchronize` | |
| MemInfo | `cudaMemGetInfo` | `hipMemGetInfo` | |
| Shuffle | `__shfl_down_sync(mask,v,d)` | `__shfl_down(v,d)` | HIP has no mask param |
| FMA | `__fmaf_rn(a,b,c)` | `fmaf(a,b,c)` | |
| Cache load | `__ldg(ptr)` | `__ldg(ptr)` | Supported in HIP |
| Vec load | `uint4` | scalar loads | Verify HIP uint4 compat |
| Warp size | 32 (hardcoded) | `WARP_SIZE` macro | 64 for CDNA, 32 for RDNA |
| File ext | `.cu` | `.hip` | hipcc convention |
| File ext | `.cuh` | `.hip.h` | hipcc convention |
| Compiler | `nvcc` | `hipcc` | |
| Arch flag | `-arch=sm_89` | `--offload-arch=gfx942` | |
| Linker | `-lcufile` | *(removed)* | |
